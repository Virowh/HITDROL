## Исправления по проверке на портативке

30 октября 2026 года.

- Исправлена причина пропуска выбранного автозапуска в полном мастере MSI: установка свойства `ADDLOCAL` после `CostFinalize` заменена событиями `AddLocal` / `Remove`, которые применяют текущее состояние каждого флажка. Прежние тихие тесты передавали флажки до расчёта установки и этого случая не проверяли. Новый `verify-installer-options.ps1` читает события из готового MSI, проверяет все четыре сочетания флажков после расчёта и изменение пути в нативной сессии Windows Installer. На 0.4.0 эта регрессионная проверка отклоняет прежние события; на 0.4.1 все четыре сочетания применяются правильно.
- В мастер добавлены редактируемый путь и «Обзор…»: доступные диски, папки, переход вверх, создание папки и выбор. Используются стандартные `PathEdit`, `DirectoryCombo`, `DirectoryList`, `SetTargetPath`. Проверка поздней смены пути включает кириллицу и пробелы. Изменение существующей установки выполняется обновлением версии, а не перенастройкой папки при восстановлении.
- Старый продукт при обновлении удаляется до записи автозапуска новой версии. В приложении явно выбран 64-битный раздел Run, запись перечитывается после сохранения, ошибки доступа больше не игнорируются. Обычное открытие приложения по-прежнему не сбрасывает выключение в диспетчере задач.

До него окно подготавливается скрытым; первый кадр отправляется напрямую, поскольку Windows подавляет обычную перерисовку скрытых окон. Если драйвер требует видимое окно для получения поверхности, окно показывается для повтора, а таймер всё равно ждёт успешного кадра. Под непрозрачной заставкой не строится интерфейс библиотеки. Начальный ледяной фон виден и в состоянии ожидания фокуса.

Новый тест моделирует десятисекундную задержку первой GPU-отправки: заставка сохраняет нулевое время до успешного кадра, затем отсчитывает свои 2,5 секунды и останавливается без фокуса. Пройдены строгий Clippy и release-сборка.
- Release-заставка проверена в четырёх разрешениях, в движении при 30/60 FPS, в полном экране и при отключении. В 11 сценариях на этом ПК первый кадр — 0,54–0,67 с; продолжительность анимации — 2,503–2,531 с, минимальные интервалы кадров — 33,368 / 16,698 мс. Три дополнительных повторных живых запуска сняли середину анимации и прошли проверку наличия голубых слоёв, чтобы чёрный кадр не считался успешным снимком. Показатели относятся к этому ПК, а не к портативке пользователя.
- Через `verify-installer.ps1` проверены установка/запуск/удаление настоящего MSI в обычной папке и на другом диске с кириллицей/пробелами, оба выбора автозапуска и ярлыка. С параметром `-PreviousPackage` выполнено обновление 0.4.0 → 0.4.1 со сменой пути: в системной автозагрузке осталась команда новой версии, старый EXE удалён, ярлык обновлён, контрольная сумма пользовательской библиотеки сохранена. Визуальная автоматизация окон `msiexec.exe` здесь недоступна по политике инструмента; логика мастера проверяется отдельно через нативные API MSI.

## Измерения release

Демонстрационная библиотека без загруженных обложек: первый кадр примерно **0,48–0,54 с**, рабочая память **107–116 МиБ**. При открытой настоящей библиотеке и локальных изображениях получено **141 МиБ**, CPU в отдельном пятисекундном замере простоя — **0,62% одного логического ядра** (около 0,03% общей мощности 24 потоков). Фоновое чтение ярлыков во время импорта в этот замер не входит.

Пределы проверены при непрерывных запросах кадров и библиотеке из 1000 записей. Интервалы измеряются между началами кадров; стартовые кадры исключены из таблицы.

## Проверки на портативке

1. Запустить из распакованного ZIP. Проверить читаемость при своём Windows DPI и работу полного экрана / F11.
2. Только геймпадом пройти главную, поиск, фильтры, добавление, проводник, редактирование, выбор обложки и запуск. Отключить и подключить контроллер; удерживаемая при подключении кнопка A не должна сработать до отпускания.
3. Повторить основные действия сенсором. Провести пальцем по карточкам: свайп не должен запускать игру. Переключиться с сенсора на геймпад и обратно.
4. Запустить настоящую игру каждого магазина, вернуться в HITDROL, проверить выделение и отсутствие перехвата ввода во время игры. Полные игровые сессии и переключение фокуса настоящих игр на ПК этой проверкой не покрыты.
5. Отключить внешний диск, обновить библиотеку, затем подключить его обратно. Записи должны остаться. Отсутствие записей при повторном сканировании покрыто автотестом; физическое отключение накопителя не выполнялось.
6. При наличии собственного SteamGridDB-ключа проверить реальный поиск, неоднозначные названия и загрузку. Живой API с личным ключом в этой проверке не использовался. Проверить работу сохранённых обложек без сети.
7. Сравнить нагрузку и расход батареи при 30/40/60 FPS на своём устройстве. Замеры ПК с дискретной GPU не предсказывают расход батареи портативки.

## Известные границы

Нет установки игр, подключения аккаунтов, настроек TDP/вентиляторов, оверлея и замены оболочки Windows. Сборка не подписана цифровой подписью. Поддерживается XInput; устройства, доступные только через DirectInput, требуют внешнего преобразования. Ярлыки `.lnk` выполняются с исходными параметрами Windows Shell и должны оставаться на диске. При выборе окна система может запускать клиент магазина, и его диалоги обрабатываются самим клиентом.

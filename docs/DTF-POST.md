# Делаю HITDROL — единый лаунчер Steam, Epic и GOG для Windows-портативок

Привет! Хочу показать HITDROL — бесплатный игровой лаунчер для портативных ПК на Windows 11. Идея простая: собрать игры из разных магазинов на одном экране и сделать их запуск удобным с геймпада и сенсора.

Проект ориентирован на устройства вроде ONEXPLAYER, ASUS ROG Ally и MSI Claw. Хотелось сделать интерфейс с крупными карточками и понятной навигацией, чтобы для выбора игры не приходилось каждый раз возвращаться к рабочему столу и переключаться между несколькими библиотеками.

Сейчас готова **HITDROL Beta 0.1**. Это ранняя версия, которой хочу поделиться и собрать обратную связь.

## Что уже работает

- **Общая библиотека Steam, Epic Games и GOG.** Установленные игры обнаруживаются автоматически. Есть режим всей библиотеки: Steam читает локальные данные текущего аккаунта, для Epic и GOG предусмотрено отдельное подключение.
- **Управление с XInput-геймпада, сенсора, мыши и клавиатуры.** В интерфейсе есть экранная клавиатура с русской и английской раскладками, поиск и избранное.
- **Добавление сторонних игр.** Сначала лаунчер предлагает ярлыки с рабочего стола. Если нужного нет, через кнопку «Другое» можно открыть встроенный проводник и выбрать файл.
- **Обложки и оформление.** Можно использовать изображения магазинов, поставить свои обложки и фон. Есть поддержка живых обоев через отдельно установленный Wallpaper Engine.
- **Недавние и запущенные игры.** Новые запуски попадают в историю после обнаружения процесса игры. У работающей игры кнопка «Играть» меняется на «Закрыть игру»: она отправляет обычный запрос закрытия, который игра может подтвердить или проигнорировать.
- **Настраиваемая частота кадров интерфейса.** Есть готовые значения и свой предел от 30 до 240 FPS. В простое интерфейс перерисовывается по необходимости, при сворачивании отрисовка останавливается.

Интерфейс на русском. Поддерживаются полный экран и оконный режим, предусмотрены экраны 16:9 и 16:10. Приложение написано на Rust с использованием winit, wgpu и egui.

## Как это устроено

HITDROL собирает библиотеку и передаёт запуск нужному магазину. Для игр Steam и Epic по-прежнему нужны их клиенты; загрузку, установку и обновления выполняют магазины. Для GOG также предусмотрен запуск установленной игры напрямую, если Galaxy недоступен.

Можно пользоваться только установленными играми и не подключать Epic/GOG к HITDROL. При подключении вход выполняется на сайте магазина, а токен обновления сохраняется в Windows Credential Manager. Локальная библиотека, настройки и кэш хранятся в профиле Windows.

## Что учитывать в бете

Сейчас нужна **Windows 11 x64**. Для распространения предусмотрены установщик MSI и портативный ZIP, который нужно распаковать целиком и запустить через `HITDROL.exe`. Приложение пока без цифровой подписи. На GitHub сейчас опубликованы исходники; готовые пакеты приложения ещё не выложены.

В этой версии нет управления TDP и вентиляторами, игрового оверлея или замены оболочки Windows. Поддержка контроллеров рассчитана на XInput. Совместимость со всеми моделями портативок и всеми играми пока не подтверждена: особенно интересны отзывы о сенсоре, навигации и поведении после возвращения из игры.
